# 렉스턴 차량모드 (Rexton Sports)

휴대폰(갤럭시)에서 여는 **"안드로이드 오토 비슷한" 차량용 화면** 앱입니다.
앱을 켜면 가로 전체화면에 큰 시계와 **🧭 네비 / 🎵 음악 / ▶ 유튜브** 세 칸만 나옵니다.
이 화면을 삼성 **Smart View(화면 미러링)** 로 렉스턴 스포츠의 순정 외 헤드유닛(JY커스텀 N90)에 띄워서 씁니다.

## 휴대폰에 설치하기 (GitHub 로그인 필요 없음)

**다운로드 주소 (항상 최신):**
https://github.com/whdydals0331-afk/Rexton-Sports/releases/download/latest/rexton-carmode.apk

> 이 주소는 GitHub Actions 첫 빌드가 성공한 뒤부터 열립니다. 또 저장소가 **공개(Public)** 여야 로그인 없이 받아집니다
> (비공개 저장소면 휴대폰에서 404 가 뜹니다).

1. 휴대폰의 **삼성 인터넷** 또는 **Chrome** 에서 위 주소를 엽니다 → `rexton-carmode.apk` 가 받아집니다.
2. 받은 파일을 누릅니다.
3. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**(지금 쓰는 브라우저에 대해)을 켜고 돌아와서 **설치**를 누릅니다.
4. Play 프로텍트가 "알 수 없는 앱"이라고 하면 **무시하고 설치**(또는 "세부정보 → 설치")를 누릅니다.
   이 앱은 권한을 하나도 요청하지 않습니다 (인터넷·위치·연락처·접근성 모두 없음).

**업데이트**: 같은 주소에서 다시 받아 설치하면 기존 앱 위에 덮어써집니다 (설정은 유지).

## 차에서 쓰는 법

1. 차에서 N90 의 **미러링 앱**을 켭니다. ← 직접 한 번
2. 휴대폰에서 이 앱 아이콘을 누릅니다. **출발 모드**(기본 켜짐)가 나머지를 이어서 합니다 — 아래 참고.
   - 출발 모드를 껐다면: **"📺 Smart View 연결"** 을 누른 뒤 목록에서 **JY_G_135c** 를 고릅니다.
   - 버튼으로 안 열리면: 빠른 설정(화면 위에서 **두 번** 내리기) → **Smart View** → **JY_G_135c**
3. 휴대폰을 **가로로** 두면 차 화면에 크게 나옵니다.
4. **조작은 휴대폰에서** 합니다.

## 🚗 출발 모드 (앱을 열면 자동으로 이어서 해 주는 것)

앱 아이콘을 누르면 아래 순서가 저절로 진행됩니다.

1. **Smart View 기기 고르는 창**이 뜹니다 → 목록에서 **JY_G_135c** 를 누릅니다. ← 직접 한 번
   그다음 이 앱 화면으로 돌아옵니다 (보통은 연결되면 저절로 돌아옵니다. 안 돌아오면 최근 앱 버튼으로).
2. 돌아오면 먼저 **재생** 신호를 보내서, 마지막으로 듣던 음악(예: YouTube Music)이 뒤에서 이어 나오게 합니다.
   이어 재생이 안 되면 그때 **음악 앱**(🎵 음악 칸에 고른 앱)을 열고 약 3초 뒤 다시 재생 신호를 보냅니다.
3. 약 2초 뒤 **네비 앱**(🧭 네비 칸에 고른 앱)이 앞으로 나옵니다. 음악은 뒤에서 계속 나옵니다.

**직접 누르는 것은 두 가지뿐입니다: N90 의 미러링 앱 한 번, Smart View 목록의 JY_G_135c 한 번.**

- 진행 중에는 화면 위쪽에 상태 줄("Smart View 연결 후 이 화면으로 돌아오세요" → "음악 재생 중…" → "네비 실행 중…")과 **취소** 버튼이 보입니다.
- Smart View 창이 안 뜨고 안내 창만 나왔다면(기종에 따라), 빠른 설정으로 연결한 뒤 상태 줄의 **"음악·네비 시작 ▶"** 을 누르세요.
- **언제 시작하나요?** 사용자가 **앱 아이콘을 눌러 열었을 때**, 또는 아래 줄의 **🚗 출발** 버튼을 눌렀을 때 **뿐**입니다.
  블루투스 연결·충전·부팅 같은 다른 계기로는 절대 시작하지 않습니다 (이 앱에는 그런 기능 자체가 없습니다).
- 앱을 연 동안 **한 번만** 돕니다. 운전 중에 이 앱으로 잠깐 돌아오거나 화면을 돌려도 다시 시작하지 않습니다.
  (앱을 1시간 넘게 안 쓰다가 아이콘으로 다시 열면 새로 연 것으로 봅니다)
- 위쪽 **"🚗 출발 모드: 켜짐/꺼짐"** 버튼으로 자동 진행을 켜고 끕니다. 꺼 두어도 아래 줄 **🚗 출발** 을 누르면 그때 한 번 돌아갑니다.
- 옆의 **⚙** 를 누르면 단계별로 켜고 끌 수 있습니다: Smart View / 음악 자동 재생 / 네비 자동 실행, 그리고 기다리는 시간(재생 키까지 1~6초, 네비까지 1~3초).
- 진행 중에 네비·음악·유튜브 칸이나 📞 전화를 직접 누르면 남은 단계는 멈춥니다.
- 음악은 **🎵 음악 칸에 고른 앱**으로 갑니다. 기본값은 **YouTube Music** 이고, 다른 앱은 음악 칸의 ⚙ 에서 고릅니다.

> 블루투스가 연결되면 앱이 저절로 열리게 하는 삼성 "모드 및 루틴" 자동 실행은 **권장하지 않습니다.**
> 차에 탈 때마다 하던 일을 끊고 튀어나와서 불편합니다. 이 앱은 아이콘을 눌렀을 때만 움직입니다.

팁
- 네비/유튜브를 연 뒤에도 차 화면에 가로로 크게 나오게 하려면 휴대폰의 **자동 회전**을 켜 두세요.
  (이 앱은 항상 가로지만, 다른 앱의 방향은 그 앱과 휴대폰 설정이 정합니다)
- 휴대폰 화면(약 19.5:9)이 차 화면(약 16:9, 1024x600)보다 길쭉해서 위아래에 검은 띠가 생길 수 있습니다.
  Smart View 설정에 "휴대폰 화면 비율 / 연결된 기기에서 전체 화면" 같은 옵션이 있으면 바꿔 보세요 (기종·버전마다 다름, 미확인).
- 이 앱으로 돌아오려면 최근 앱 버튼이나 홈 화면 아이콘(핸들 모양)을 쓰세요.

## 칸마다 앱 바꾸기

- 칸을 **길게 누르거나** 칸 오른쪽 위 **⚙** 를 누르면, 설치된 후보 앱 목록이 나옵니다.
- 목록에 원하는 앱이 없으면 **"기타 앱 고르기"** → 홈 화면에 아이콘이 있는 모든 앱 중에서 고를 수 있습니다.
- 고른 앱은 기억됩니다. 처음에는 설치된 후보 중 첫 번째가 자동으로 들어갑니다.
- 후보 앱이 하나도 없으면 칸에 "앱 없음 — 눌러서 고르기" 가 나옵니다.

| 칸 | 후보 (앞쪽이 기본값 우선) |
|---|---|
| 🧭 네비 | T맵, 카카오내비, 네이버 지도, 카카오맵, 구글 지도, 아틀란 |
| 🎵 음악 | YouTube Music, 멜론, 지니, Spotify, FLO, 벅스, 삼성 뮤직 |
| ▶ 유튜브 | YouTube, YouTube ReVanced |

아래 줄: **📞 전화**(전화 키패드 열기), **🚗 출발**(출발 순서 지금 실행), **🏠 나가기**(이 앱 닫기). 위쪽 **?** 는 사용법 다시 보기.

## 솔직한 한계

- **진짜 안드로이드 오토가 아닙니다.** 휴대폰 화면을 그대로 비추는 것(미러링)이라, 차 화면을 터치해도 아무 일도 없습니다. **조작은 휴대폰에서만** 됩니다.
- **출발 모드의 "재생"은 음악 앱에 달려 있습니다.** 이 앱은 휴대폰 시스템에 "재생 버튼 눌림" 신호만 보냅니다.
  음악 앱이 아직 준비가 안 됐거나 재생할 곡이 없으면 아무 일도 안 일어날 수 있습니다 (그때는 음악 앱에서 직접 ▶).
- **출발 모드의 네비 실행은 경우에 따라 막힐 수 있습니다.** 이어 재생이 되면 이 앱이 앞에 있는 채로 네비를 열어서 문제가 없습니다.
  이어 재생이 안 돼서 음악 앱을 연 경우에는 이 앱이 뒤에 있을 때 네비를 열게 되는데, 안드로이드가 이를 막을 수 있습니다.
  그때는 이 앱으로 돌아와 🧭 네비 칸을 누르세요.
- **Smart View 연결은 매번 직접 골라야 합니다.** 삼성은 다른 앱이 미러링을 몰래 시작하는 방법을 열어두지 않았습니다.
  "Smart View 연결" 버튼은 기기 고르는 창을 **여는 데까지만** 도와줍니다 (기종에 따라 이것도 안 되면 빠른 설정 안내가 나옵니다).
- 네비·음악·유튜브는 각 앱이 그대로 열립니다. 그 앱들의 화면을 차에 맞게 바꿔주지는 않습니다.
- 앱 화면을 보는 동안 화면이 꺼지지 않게 해 두었습니다. 휴대폰 배터리·발열에 주의하세요(충전 연결 권장).
- 운전 중 휴대폰 조작은 위험하고 법으로도 제한됩니다. 출발 전에 경로·음악을 정해 두세요.

## 검증 상태

- GitHub Actions 에서 빌드합니다 (`.github/workflows/build-apk.yml`). 빌드할 때마다 위 다운로드 주소가 새 APK 로 바뀝니다.
- 소스는 개발 환경에서 Android 15(API 35) 프레임워크 클래스에 대고 `javac` 컴파일까지 확인했습니다.
  Gradle 전체 빌드(리소스 처리·APK 서명 포함)는 개발 환경에서 돌리지 못했고, **첫 GitHub Actions 빌드가 첫 실제 검증**입니다.
- **아직 대표님의 갤럭시 S23+ 에서 실행해 보지 않았고, 차(N90)에서 미러링으로도 확인하지 않았습니다.**
  특히 "Smart View 연결" 버튼이 S23+ 에서 기기 고르는 창을 바로 여는지는 실제로 눌러봐야 압니다.
- **출발 모드도 기기에서 아직 확인하지 않았습니다.** 확인이 필요한 것:
  - Smart View 에서 JY_G_135c 를 고른 뒤 이 앱으로 저절로 돌아오는지, 돌아왔을 때 음악·네비가 이어지는지
  - 재생 키로 실제 재생이 시작되는지 — **음악 앱마다 다릅니다** (YouTube Music / 멜론 등 각각 확인 필요)
  - 네비가 마지막에 앞으로 나오는지 (위 "막힐 수 있습니다" 참고)
  - 앱을 오래 뒤에 두었다가 아이콘으로 다시 열었을 때 다시 시작하는지 (1시간 기준)

## 개발자용 메모

- Java + 안드로이드 기본 View 만 사용 (라이브러리 없음). minSdk 26 / targetSdk 35 / compileSdk 35, AGP 8.7.3, Gradle 8.14.3.
- 빌드: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/`
- 버전: CI 빌드 번호(`GITHUB_RUN_NUMBER`)가 versionCode, `1.0.<번호>` 가 versionName.
- **서명 키**: `app/debug.keystore` (비밀번호 `android`, 별칭 `androiddebugkey`) 를 저장소에 일부러 올려 두었습니다.
  CI 가 매번 같은 키로 서명해야 휴대폰에서 "업데이트" 설치가 되기 때문입니다.
  개인용 사이드로드 앱이라 허용한 방식이며, 이 키를 다른 앱(특히 Play 스토어 배포)에는 쓰지 마세요.
  키를 바꾸면 휴대폰에서 기존 앱을 지우고 다시 설치해야 합니다.
- 출발 모드: 설정·재생 키는 `Departure.java`, 진행(대기·예약·취소)은 `MainActivity` 의 "출발 모드" 부분.
  권한·리시버·서비스 없음 — 시작 계기는 앱을 연 것(`onResume` 한 번, 회전·복원 시 `savedInstanceState` 로 중복 방지)과 🚗 출발 버튼뿐.
  예약은 메인 `Handler` 로 하고 취소/`onDestroy` 에서 지운다.
- 패키지 가시성(Android 11+): `QUERY_ALL_PACKAGES` 없이 `AndroidManifest.xml` 의 `<queries>` 로 후보 패키지와 런처 앱 목록만 봅니다.
  후보 앱을 추가하려면 `Category.java` 와 `<queries>` **두 곳**에 넣으세요.
