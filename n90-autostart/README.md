# N90 자동실행 (2단계)

쌍용 렉스턴 스포츠의 **JY커스텀 N90** 헤드유닛(Android 4.4)에서, 시동을 걸 때
**"스마트폰 미러링" 수신 앱을 자동으로 한 번 열어 주는** 작은 앱입니다.

- 패키지: `com.jydiag.n90auto` / 앱 이름: **N90 자동실행**
- 루팅·펌웨어 수정 없음. 기기 설정을 하나도 바꾸지 않습니다.
- 권한은 `RECEIVE_BOOT_COMPLETED` **하나**뿐입니다 (인터넷·저장소 권한 없음).
- 1단계 진단 앱(`../n90-diagnostic`, `com.jydiag.n90`)과는 별개의 앱입니다. 둘 다 설치해도 됩니다.

## 왜 필요한가

갤럭시 S23+ 의 Smart View 는 헤드유닛의 미러링 수신 앱(기기 이름 `JY_G_135c`)이 **한 번 열려 있어야**
헤드유닛을 찾습니다. 열어 둔 뒤 다른 화면으로 나가도 연결은 유지되지만, 시동을 다시 걸면
JY Home(런처)만 뜨고 수신 앱이 안 열려 있어서 폰이 헤드유닛을 못 찾습니다.
이 앱은 "시동 후 수신 앱을 손으로 여는 동작"을 대신하려는 것입니다.

## 동작 방식

1. 시스템 신호를 받습니다 (아래 목록). 받은 신호는 **전부 기록**합니다.
2. 자동 실행이 켜져 있고, 실행할 앱이 골라져 있고, 마지막 예약 후 120초가 지났으면
   `AlarmManager` 로 순서를 예약합니다. (상주 서비스 없음)
   - 신호 → **지연(기본 8초)** → 앱 실행
   - (선택) **한 번 더 실행** — 첫 실행이 Wi-Fi 가 켜지기 전이었을 경우 대비 (기본 꺼짐, 20초 후)
   - (선택) **실행 후 홈으로 돌아가기** — 사용자가 수신 앱을 연 뒤 다른 화면으로 나가는 동작을 흉내 (기본 꺼짐, 10초 후)
3. 예약 시각에 내부 수신기가 앱을 실행하고 결과(성공/실패 이유)를 기록합니다.

### 듣는 신호 (정확한 action 이름)

| action | 처리 |
|---|---|
| `android.intent.action.BOOT_COMPLETED` | 실행 신호 |
| `android.intent.action.QUICKBOOT_POWERON` | 실행 신호 |
| `com.htc.intent.action.QUICKBOOT_POWERON` | 실행 신호 |
| `android.intent.action.USER_PRESENT` | 실행 신호 (약한 신호 — 아래 안전장치 참고) |
| `android.intent.action.ACTION_POWER_CONNECTED` | 실행 신호 (약한 신호 — 아래 안전장치 참고) |
| `android.intent.action.ACC_ON` | 실행 신호 (**검증 안 된 추측**) |
| `com.android.action.ACC_ON` | 실행 신호 (**검증 안 된 추측**) |
| `android.intent.action.ACC_ON_BROADCAST` | 실행 신호 (**검증 안 된 추측**) |
| `com.cayboy.action.ACC_ON` | 실행 신호 (**검증 안 된 추측**) |
| `android.intent.action.MY_PACKAGE_REPLACED` | **기록만** (절대 실행 안 함) |

`SCREEN_ON` 은 안드로이드 규칙상 상주 서비스 없이는 받을 수 없어서 쓰지 않습니다.

### 안전장치

- **쿨다운 120초**: 같은 부팅 안에서 마지막 예약 후 120초 안에 온 신호는 무시합니다
  (BOOT_COMPLETED 와 USER_PRESENT 가 같이 오거나, 실행된 앱이 뭔가를 다시 일으켜도 반복 실행되지 않음).
  재부팅 여부는 `/proc/sys/kernel/random/boot_id` 로 구분합니다 (못 읽으면 시계 기반 추정).
- **약한 신호 제한**: `USER_PRESENT`(화면 켜짐/잠금 해제)·`ACTION_POWER_CONNECTED` 는 운전 중에
  화면을 껐다 켜기만 해도 다시 올 수 있어서, 그때마다 수신 앱이 내비 위로 뜨지 않게 합니다.
  같은 부팅 안에서는 **마지막 예약 후 30분이 지났거나, 그 사이 기기가 1분 이상 잠들었다 깨어난 경우**
  (시동을 껐다 켠 것으로 추정)에만 실행 신호로 씁니다. 막힌 경우에도 신호는 이유와 함께 기록됩니다.
  (잠든 시간은 부팅 후 경과 − uptime 으로 계산합니다. N90 이 시동을 꺼도 실제로 잠들지 않는 기기라면
  30분 안에 다시 시동을 걸 때 이 두 신호로는 실행되지 않을 수 있습니다 — 기록에 "건너뜀"으로 보입니다)
- 같은 신호가 여러 번 와도 예약은 쌓이지 않고 마지막 것으로 바뀝니다.
- 자기 자신은 실행하지 않습니다. 고른 앱이 지워졌으면 실행하지 않고 기록만 남깁니다.
- **"자동 실행 끄기"를 누르면 대기 중인 예약도 즉시 취소**됩니다.
- 설정 변경·Wi-Fi 조작·다른 앱 종료·명령 실행을 하지 않습니다. 런처(HOME)를 대체하지 않습니다.

## 설치와 첫 사용

1. GitHub Actions 의 `n90-autostart-apk` 워크플로 결과에서 `n90-autostart-debug-apk` 아티팩트를 받아
   APK 를 USB 등으로 헤드유닛에 설치합니다.
2. **설치 후 "N90 자동실행" 앱을 반드시 한 번 엽니다.**
   안드로이드 3.1 이상은 한 번도 열지 않은 앱(정지 상태)에 부팅 신호를 보내지 않습니다.
   기록에 "앱 화면 열림"이 찍히면 된 것입니다.
3. **앱 고르기** → ★ 표시된 미러링 후보 중 "스마트폰 미러링" 앱을 선택합니다.
   - 목록에 없으면 "모든 앱 보기"를 누릅니다 (아이콘 없는 앱 포함).
   - 기본 실행 화면으로 안 되면 앱을 누르고 **"화면(액티비티) 직접 고르기"** 로 특정 화면을 고릅니다.
   - 1단계 진단 앱 보고서에 나온 패키지명과 맞춰 보면 확실합니다.
4. **지금 실행 테스트**를 눌러 수신 앱이 열리는지, 그 상태에서 폰 Smart View 가 `JY_G_135c` 를 찾는지 봅니다.
5. 필요하면 **순서 테스트**로 지연·홈으로 돌아가기까지 한 번 돌려봅니다 (자동 실행이 꺼져 있어도 동작).
6. **자동 실행 켜기**를 누릅니다 (앱을 고르기 전에는 켜지지 않습니다).
7. 시동을 껐다가 (잠시 기다린 뒤) 다시 켜고, 이 앱을 열어 **기록**을 봅니다. **공유** 버튼으로 기록을 보낼 수 있습니다.
   - 어떤 신호가 찍혔는지 → N90 이 시동 때 보내는 신호를 알 수 있습니다.
   - **아무 신호도 안 찍혔으면** → N90 이 이 앱이 듣는 신호를 보내지 않는 것입니다 (아래 "검증 안 된 것" 참고).
   - 화면 위쪽 **"부팅 후 경과"** 가 시동 직후인데도 크다면(수십 분 이상) → 헤드유닛이 재부팅이 아니라
     잠들었다 깨어나는 방식(퀵부트/ACC 슬립)입니다.

## 끄기 / 지우기

- 끄기: 앱에서 **자동 실행 끄기** (대기 중 예약도 즉시 취소).
- 완전히 되돌리기: 설정 > 앱에서 **제거**. 기기 설정을 바꾼 것이 없으므로 제거하면 설치 전과 똑같습니다.
- 참고: 설정 > 앱에서 이 앱을 **강제 중지**하면 다시 "정지 상태"가 되어 자동 실행이 안 됩니다.
  다시 쓰려면 앱을 한 번 열어 주세요.

## 검증된 것 / 안 된 것

**확인한 것 (코드 수준)**
- Android 4.4(API 19) 프레임워크 jar 로 자바 소스 컴파일 통과, API 19 에 없는 호출·람다·자바 8 라이브러리 미사용.
- 매니페스트/워크플로 문법 검사 통과. APK 빌드는 GitHub Actions 에서 합니다.

**아직 모르는 것 (실차에서 확인해야 함)**
- N90 에 설치·실행이 되는지.
- **시동 때 위 신호 중 어떤 것이라도 오는지.** 퀵부트(잠들었다 깨는) 방식의 헤드유닛은
  위 신호를 **하나도 안 보낼 수도** 있습니다. 기록이 그 답을 알려 줍니다.
  (안 오면 1단계 진단 결과와 함께 다른 방법을 찾아야 합니다)
- 다른 앱이 수신 앱을 실행해도 손으로 연 것처럼 **Smart View 가 헤드유닛을 찾게 되는지**.
- **홈으로 돌아간 뒤에도 연결 대기 상태가 유지되는지** (손으로 할 때는 유지된다고 확인됨).
- "홈으로 돌아가기"·"한 번 더 실행"은 그 순간 다른 화면(내비 등)을 보고 있어도 동작합니다
  (권한 없이 지금 화면이 무엇인지 알 수 없어서). 필요할 때만 켜세요.

**이 앱이 하지 않는 것**
- **폰 쪽 자동 연결은 이 앱이 해결하지 않습니다.** 헤드유닛이 찾을 수 있는 상태가 되어도,
  갤럭시 S23+ 에서 Smart View 를 시작하는 것은 여전히 폰에서 해야 합니다.
- 폰 쪽은 삼성 **"모드 및 루틴"**(예: 차량 블루투스 연결 시 동작)으로 자동화할 수 있을지
  나중에 시험해 볼 만하지만, **Smart View 시작/특정 기기 연결이 되는지는 확인되지 않았습니다.**

## 파일 구성

```
n90-autostart/
  app/src/main/AndroidManifest.xml      권한 1개, 수신기 2개(외부 신호용 / 내부 예약용), 액티비티 2개
  app/src/main/java/com/jydiag/n90auto/
    MainActivity.java     상태·설정·기록 화면 (가로 화면에서 2단)
    PickerActivity.java   실행할 앱/화면 고르기
    TriggerReceiver.java  시스템 신호 수신 → 기록 → 조건 맞으면 예약
    StepReceiver.java     예약 시각에 실행/한 번 더/홈으로 (exported=false)
    Launcher.java         실행·홈 이동·예약·취소
    Store.java            설정값, 쿨다운, 이벤트 기록(최근 200개)
```
